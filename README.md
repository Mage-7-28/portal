# Portal

> 跨平台 SSH / SFTP 桌面客户端

Portal 用于在本地电脑和远程服务器之间浏览、管理和传输文件，也提供一个独立的 SSH 远程终端。支持 macOS、Windows 和 Linux 客户端，以及常见的 Linux、Windows Server、macOS 和 BSD 服务器。

[项目主页](https://gitee.com/Mage-7-28/portal) · 当前版本 `2.0.0` · [MIT License](./LICENSE)

## 主要功能

### 安全连接

- 支持自定义主机、端口、用户名和密码。
- 连接配置可以保存，密码只在当前运行期间保留，不写入配置文件或终端窗口地址。
- 首次连接会显示服务器 SHA-256 主机指纹，确认后才建立连接。
- 后续连接会继续校验指纹；指纹变化时会阻止连接并提示核对服务器身份。
- 自动检测连接状态，服务器断开后及时清理当前会话。

### 文件管理

- 浏览远程用户主目录，输入路径快速跳转，也可以返回上级和刷新目录。
- 支持 POSIX 路径和 Windows 盘符样式路径，实际可访问范围取决于服务器权限。
- 上传和下载文件、文件夹，支持原生文件选择器、拖拽和批量操作。
- 显示实时进度，可以取消传输；覆盖已有文件前会进行确认。
- 新建目录、重命名、删除文件，以及递归删除文件夹。
- 传输完成前使用临时文件，降低中断后留下不完整文件的风险。

### 文件预览

- 支持常见图片、纯文本、JSON 和代码文件预览。
- 代码文件提供语法高亮，JSON 支持格式化显示。
- 单个文件预览上限为 5 MiB；压缩包、办公文档和其他不支持的文件请下载后使用本地应用打开。

### 远程终端

- 在独立窗口中打开 SSH PTY 终端。
- 支持 ANSI/VT 控制序列、终端尺寸调整和交互式命令行程序。
- 终端和文件传输使用独立会话，关闭终端或断开连接时会释放远程资源。

## 目录大小统计

目录大小会在目录行进入可视区域时按需计算，不会把远程文件内容下载到本地。Portal 会根据服务器环境自动选择合适的方式：

| 服务器环境 | 处理方式 |
| --- | --- |
| Linux 等 Unix 系统，且提供兼容的 `du` 命令 | 优先在服务器本机汇总，通常更快 |
| Windows Server、Windows 盘符路径，或没有兼容 `du` 的系统 | 自动使用 SFTP 递归统计 |
| macOS、BSD、BusyBox 等命令参数不兼容的系统 | 自动回退到 SFTP 递归统计 |

统计任务会按需排队、复用结果并支持取消，避免打开大目录时阻塞正常的浏览和传输操作。权限不足的子目录会显示部分结果：

- 显示具体大小：统计已完成。
- 显示 `≥`：已统计可访问内容，实际大小可能更大。
- 显示“不可用”：当前无法完成统计，可以检查权限或稍后重试。

## 支持的平台

### 客户端

| 系统 | 支持情况 |
| --- | --- |
| macOS | 支持原生窗口、路径和文件选择器 |
| Windows | 支持 Windows 路径、盘符和原生文件选择器 |
| Linux | 支持常见桌面环境及 Linux 路径 |

### 远程服务器

远程服务器需要满足以下条件：

- SSH 服务可连接，端口和账户凭据有效。
- 已启用 SFTP 子系统，并允许当前账户访问目标目录。
- 使用文件浏览和传输不要求远程 Shell；Shell 只用于可选的目录大小快速统计和远程终端。

## 快速开始

1. 打开 Portal，在“SSH 连接”页面选择“新建连接”。
2. 填写连接名称、主机、端口、用户名和密码，可先点击“测试连接”。
3. 首次连接时核对服务器 SHA-256 指纹，确认无误后选择信任。
4. 双击连接配置进入远程用户主目录，双击文件夹继续浏览。
5. 使用“上传”选择本地文件或文件夹，也可以直接拖拽；点击文件或文件夹右侧的下载按钮即可下载。
6. 双击支持的文件可预览，点击“打开终端”可使用远程 Shell。

## 使用提示

- 单击项目可选择；在 Windows/Linux 使用 Ctrl、在 macOS 使用 Cmd 进行多选，使用 Shift 选择连续范围。
- 首次下载时需要选择本地下载目录，之后可以从菜单“下载路径”修改。
- 远程文件夹大小统计受网络速度、目录规模和账户权限影响，大目录首次统计可能需要等待。
- 本地符号链接和特殊文件不会在文件夹传输中被跟随或复制，远程目录大小也不会跟随符号链接。
- 目前仅支持密码认证，不支持私钥、SSH Agent、键盘交互认证或跳板机配置。
- 当前版本尚未提供自动更新；升级时请安装新版本安装包。

## 安全说明

- 文件浏览、上传、下载和远程操作均通过加密的 SSH/SFTP 会话完成。
- 首次连接请认真核对主机指纹；服务器更换密钥时，不要未经核实直接重新信任。
- 密码不会写入连接配置、终端窗口地址或应用日志，但会在当前进程内存中使用。
- 请不要把密码、主机指纹、服务器地址或操作日志发布到公开 Issue、截图或讨论中。
