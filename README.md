Portal 用于在本地电脑和远程服务器之间浏览、管理和传输文件，也提供独立的 SSH 远程终端。项目基于 Tauri 2、React 和 Rust 开发，当前主要面向 macOS 进行开发、验证和打包发布。

Windows 和 Linux 的构建配置仍保留在项目中，但目前没有提供经过项目作者持续验证的官方安装包。欢迎在对应系统上自行构建和测试，并通过 Issue 反馈兼容性问题。

## 项目状态

| 平台 | 官方安装包 | 说明 |
| --- | --- | --- |
| macOS | DMG | 当前主要开发、验证和发布平台 |
| Windows | 暂无 | 可在 Windows 环境自行构建尝试 |
| Linux | 暂无 | 可在 Linux 环境自行构建尝试 |

远程服务器不受客户端打包平台限制。只要 SSH/SFTP 配置可用，Portal 可以连接常见的 Linux、Windows Server、macOS 和 BSD 服务器；实际可访问范围取决于服务器账户权限。

## 核心功能

### SSH / SFTP 连接

- 支持自定义连接名称、主机、端口、用户名和密码。
- 首次连接显示服务器 SHA-256 主机指纹，确认后才建立连接。
- 后续连接继续校验指纹；指纹变化时阻止连接并提示核对服务器身份。
- 连接断开后自动清理当前会话和相关资源。

### 文件管理

- 浏览远程用户主目录，支持路径跳转、返回上级和刷新目录。
- 支持 POSIX 路径和 Windows 盘符样式路径。
- 上传、下载文件和文件夹，支持原生文件选择器、拖拽和批量操作。
- 显示实时传输进度，支持取消传输和覆盖确认。
- 支持新建目录、重命名、删除文件和递归删除文件夹。
- 传输完成前使用临时文件，降低中断后留下不完整文件的风险。

### 远程目录大小

目录大小会在目录行进入可视区域时按需计算，不会把远程文件内容下载到本地。Portal 会根据服务器环境自动选择合适的策略：

| 服务器环境 | 处理方式 |
| --- | --- |
| Linux 等 Unix 系统，且提供兼容的 `du` 命令 | 优先在服务器本机汇总，通常更快 |
| Windows Server、Windows 盘符路径，或没有兼容 `du` 的系统 | 使用 SFTP 递归统计 |
| macOS、BSD、BusyBox 等命令参数不兼容的系统 | 自动回退到 SFTP 递归统计 |

统计任务支持按需排队、结果复用和取消操作。权限不足的子目录会显示部分结果，并以 `≥` 标记可能低于实际值的统计结果。

### 文件预览

- 支持常见图片、纯文本、JSON 和代码文件预览。
- 代码文件提供语法高亮，JSON 支持格式化显示。
- 单个文件预览上限为 5 MiB；压缩包、办公文档等文件请下载后使用本地应用打开。

### SSH 远程终端

- 在独立窗口中打开 SSH PTY 终端。
- 支持 ANSI/VT 控制序列、终端尺寸调整和交互式命令行程序。
- 终端和文件传输使用独立会话，关闭终端或断开连接时会释放远程资源。

### 更新检查

- 软件启动时自动检查 Gitee 最新发行版。
- 可以通过菜单“文件 -> 更新”手动检查。
- 发现新版本时显示提示，并打开 Gitee 发行版页面供用户手动下载。
- 启动提示支持“跳过此版本”；手动检查不会显示该选项。
- 当前仅提供更新检查和下载入口，不会自动下载或安装新版本。

## 下载与安装

前往 [Gitee 发行版](https://gitee.com/Mage-7-28/portal/releases) 下载对应文件。

目前官方提供 macOS DMG 安装包。下载时请根据发行版附件中的系统和架构说明选择文件。

Windows 和 Linux 暂未提供官方安装包。如果你希望在这些平台使用 Portal，可以参考下面的源码构建步骤，在对应系统上自行构建。

## 从源码构建

### 环境要求

- Node.js（建议使用当前 LTS 版本）
- pnpm
- Rust stable toolchain
- macOS 构建还需要 Xcode Command Line Tools

### 安装依赖

```bash
pnpm install
```

### 构建 macOS DMG

```bash
pnpm tauri:dmg
```

### 尝试构建 Windows 或 Linux

请在对应系统上准备 Tauri 所需的原生构建环境，然后执行项目中已有的构建脚本：

```bash
# Windows
pnpm tauri:windows

# Linux
pnpm tauri:linux
```

Windows 和 Linux 构建目前属于自行尝试，不代表项目已经提供经过完整验证的官方发行包。

## 快速开始

1. 打开 Portal，在“SSH 连接”页面选择“新建连接”。
2. 填写连接名称、主机、端口、用户名和密码，可先点击“测试连接”。
3. 首次连接时核对服务器 SHA-256 指纹，确认无误后选择信任。
4. 双击连接配置进入远程用户主目录，双击文件夹继续浏览。
5. 使用“上传”选择本地文件或文件夹，也可以直接拖拽；点击项目右侧的下载按钮即可下载。
6. 双击支持的文件可预览，点击“打开终端”可使用远程 Shell。

## 使用提示

- 单击项目可选择；Windows/Linux 使用 Ctrl、macOS 使用 Cmd 进行多选，使用 Shift 选择连续范围。
- 首次下载时需要选择本地下载目录，之后可以从菜单“下载路径”修改。
- 大目录首次统计可能需要等待，耗时取决于服务器命令、网络速度、目录规模和账户权限。

## 远程服务器要求

- SSH 服务可连接，端口和账户凭据有效。
- 已启用 SFTP 子系统，并允许当前账户访问目标目录。
- 文件浏览和传输不要求远程 Shell；Shell 只用于可选的目录大小快速统计和远程终端。
- 目录大小统计受服务器命令、网络速度、目录规模和账户权限影响。

## 已知限制

- 目前仅支持密码认证。
- 暂不支持私钥、SSH Agent、键盘交互认证或跳板机配置。
- 本地符号链接和特殊文件不会在文件夹传输中被跟随或复制，远程目录大小也不会跟随符号链接。
- Windows 和 Linux 当前没有项目作者提供的官方安装包，需要自行构建验证。

## 安全说明

- 文件浏览、上传、下载和远程操作均通过加密的 SSH/SFTP 会话完成。
- 首次连接请认真核对主机指纹；服务器更换密钥时，不要未经核实直接重新信任。
- 密码不会写入连接配置、终端窗口地址或应用日志，但会在当前进程内存中使用。
- 请不要把密码、主机指纹、服务器地址或操作日志发布到公开 Issue、截图或讨论中。
